# First Instruction Patterns

Before drafting the handoff, propose 2-3 candidate first instructions tailored to the work state as a multiple-choice question. Number the candidates and always include an explicit "or write your own" option. The chosen instruction gets embedded in the draft, so the handoff is generated once — never present candidates after the draft and regenerate.

The first instruction is the next chat's opening move. It should be specific, actionable, and small enough to execute without further input.

## Continuation patterns

1. "Continue from [step]. [Open question] is still unresolved, so address that first."
2. "Pick up the draft of [artifact]. The last section I wrote was [section name]. Draft the next section."
3. "Resume building [thing]. Confirm [decision] is still right before proceeding."
4. "Read the handoff, then keep iterating on [artifact]. Start by [specific first action]."

## Pivot patterns

1. "Read the handoff, then start [new task]. Use [output of previous chat] as input."
2. "The previous chat finished [thing]. Now document it in [destination]. Use prompt-documenter if applicable."
3. "Based on the handoff, draft [new artifact]. Do not re-design [completed thing]."
4. "Take the [output] from the handoff and [transform it into the new format]."

## Review patterns

1. "Read the handoff and identify gaps in [specific area]."
2. "Review the decisions listed in the handoff. Tell me which ones look weakest and why."
3. "Stress test the negative boundaries in [skill or design]."
4. "Read the handoff, then play devil's advocate against [decision]."

## Resume patterns

1. "I am picking this back up. Read the handoff, then ask me one clarifying question before we continue."
2. "Re-orient me. Summarize where we left off in 3 sentences, then propose the next move."
3. "Read the handoff. Confirm the next concrete step still makes sense given anything that may have changed."

## How to choose candidates

Generate candidates that match the inferred purpose. Vary them on one axis:
- Different starting actions (read first vs act first)
- Different scopes (narrow next step vs broader re-orientation)
- Different stances (continue vs question)

Do not generate three candidates that all say the same thing in different words.
